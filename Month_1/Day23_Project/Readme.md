Student Performance Analyzer (CLI)

📌 Description
A command-line based data analysis tool built using Python and Pandas.
It allows users to analyze student performance, manage records, and generate insights.

🚀 Features
View full student report
Show topper
Department-wise analysis
Pass/Fail filtering
Grade classification
Add new student
Search student (case-insensitive)
Save report to CSV


🛠️ Technologies Used
Python
Pandas


▶️ How to Run
python student_cli_analyzer.py

📊 Sample Use Cases
Analyze student performance
Track departmental results
Manage student data dynamically
