# 🏏 IPL Data Analysis Dashboard

## 📌 Overview
This project analyzes IPL data to uncover trends in team performance, player statistics, and match-winning strategies using Python and data visualization.
---
## 📊 Key Insights
- Mumbai Indians and CSK are among the most successful IPL teams
- Death overs contribute the highest scoring rates
- Certain players consistently dominate batting and bowling charts
- Toss and match phase strategies influence outcomes
---
## 🛠 Tools & Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
---
## 📈 Analysis Performed
- Team performance analysis
- Batting analysis
- Bowling analysis
- Strike rate analysis
- Economy rate analysis
- Match phase analysis
- Dashboard visualization
---
## 🚀 Project Outcome
Built a dashboard-style sports analytics project to practice real-world data analysis, storytelling, and visualization skills.
